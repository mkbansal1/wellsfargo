This block is used to embed a self-hosted video with native HTML5 controls. It supports an optional collapsible transcript section below the player.

Implementation

This block's table has 1 column and 2 or 3 rows, with the first row containing only the block name.

  • The second row contains the video source (a link to an .mp4 file) and an optional poster image (a link to a .png/.jpg file).
  • The third row (optional) contains the transcript: a title (as heading or first paragraph) followed by the transcript text paragraphs.

When rendered, CSS and JavaScript will display a native HTML5 video player with controls. If a transcript row is provided, it renders as a collapsible toggle below the video.

When to use

  • When showcasing a single self-hosted video.
  • For educational or informational videos that benefit from a text transcript.
  • For accessibility compliance — providing a transcript alongside video content.

When to consider another block

  • If embedding YouTube or Vimeo videos, use the Embed block instead.
  • If you need multiple videos in a gallery format, consider a Carousel.
  • If only a link to a video is needed without an embedded player.
