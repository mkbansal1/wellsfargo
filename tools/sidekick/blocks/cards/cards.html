Cards
description

Displays content in a consistent, card-based grid layout. Each card can contain an image, title, description, and a call-to-action link. Cards are arranged responsively — stacked on mobile, side-by-side on desktop.

When to use: To highlight multiple related features, products, services, or articles in a uniform visual style that is easy to scan.

When NOT to use: For a single feature/highlight (use Hero instead), for complex or varied layouts per item (use Columns), or for simple lists (use default content).
